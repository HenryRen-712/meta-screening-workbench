# 需求规格

## 产品定位

Meta Screening Workbench 是面向系统综述和 Meta 分析的文献筛选与证据整理工具。当前版本先保证本地稳定使用，长期目标是升级为联网可打开、多人协作、覆盖 Meta 分析全流程的平台。

## 目标用户

主要用户是不懂代码的科研人员。界面必须让用户通过明确按钮和表格完成任务，不能要求用户理解代码、数据库或命令行。

## 完整目标流程

1. 创建项目。
2. 填写研究问题、检索来源和筛选者信息。
3. 导入 RIS、BibTeX、CSV 题录。
4. 自动识别可能重复。
5. 人工处理重复记录。
6. 筛选者 A/B 独立盲筛题名摘要。
7. 揭盲并识别冲突。
8. 第三人裁决。
9. 全文获取和全文复筛。
10. 数据提取。
11. Risk of Bias 评价。
12. Meta 统计数据录入和分析。
13. PRISMA、筛选记录、数据提取表、RoB 表、Meta 结果和报告草稿导出。
14. 项目备份、恢复和后续云端同步。

## 当前必须保持可用

- 本地运行。
- 项目自动保存到浏览器。
- JSON 项目备份和恢复。
- RIS、BibTeX、CSV 导入。
- 双人盲筛。
- 第三人裁决。
- 全文复筛。
- 批量上传 PDF，并按 DOI、PMID 或完整题名文件名自动匹配题录。
- 数据提取。
- 审计日志。
- CSV、PRISMA、数据提取表、Word 草稿导出。

## v2 逐步新增

- 标签与排除理由分离。
- 高级筛选、批量操作、抽样分工。
- PICO/关键词高亮。
- Supabase 登录、项目成员和角色权限。
- 云端同步。
- AI 相关性评分和提示。
- NOS/JBI Risk of Bias。
- OR/RR/HR/MD/SMD Meta 统计。
- 森林图和基础异质性指标。

## 非目标和限制

- AI 不自动决定纳入或排除。
- 公开 GitHub 仓库不保存真实筛选数据、PDF、备份 JSON 或私密 Key。
- 云端功能上线前，本地功能必须继续可用。
- Meta 统计第一版不追求替代 R/Stata/RevMan 的全部高级功能。

## 数据字段

题录基础字段：

- 标题
- 摘要
- 作者
- 年份
- 期刊
- DOI
- PMID
- 来源数据库
- 关键词
- 来源文件

筛选字段：

- 筛选者 A 决定、理由、备注、时间
- 筛选者 B 决定、理由、备注、时间
- 第三人裁决决定、理由、备注、时间
- 最终决定

全文字段：

- 全文获取状态
- PDF 本机路径或未来云端文件引用
- PDF 本机附件名称、大小、上传时间和自动匹配方式
- 全文阶段决定
- 全文排除理由
- 全文备注

PDF 管理规则：

- PDF 文件默认仅保存至当前浏览器的 IndexedDB，不上传到 GitHub 或其他外部服务。
- 自动匹配优先级为 DOI、PMID、完整题名文件名；无法可靠匹配的 PDF 不得自动关联到题录。
- PDF 自动匹配和“未上传全文候选”导出处理双方筛选结果一致或已裁决为“纳入/待定”的全文候选，以及尚未裁决的 A/B 冲突；已排除和重复移除记录不进入该流程。
- 项目 JSON 备份仅保存 PDF 匹配元数据，不包含 PDF 二进制文件；换浏览器、换设备或清理浏览器数据后需要重新上传 PDF。
- 全文候选中未上传 PDF 的条目必须可导出标题、作者、年份、期刊、DOI、PMID、来源数据库和关键词，供后续获取全文。

最终纳入文献数据提取规则：

- “数据提取”板块支持再次批量上传 PDF，但只允许自动匹配全文最终纳入条目。
- 匹配顺序继续使用 DOI、PMID、完整题名；无法可靠匹配的文件不得自动关联。
- 一键提取字段覆盖研究设计、地区、数据来源、研究对象、刷牙暴露定义与分组、结局定义、效应量、原始频数、统计模型、调整变量、亚组、敏感性分析、缺失数据、资助和利益冲突等 Meta 分析主要信息。
- 每个自动提取字段必须保存 PDF 原文片段、页码、提取时间和 PDF SHA-256；没有证据的字段保持空白并显示“未从 PDF 自动确认”。
- 自动提取仅生成待人工核验草稿，不得进行缺失信息补写，不得把讨论部分或其他研究的结果当成本研究结果，不得覆盖人工填写内容。
- 扫描版、受保护 PDF、图片表格和无法可靠解析的跨行表格必须明确报错或留空，不得生成猜测值。

后续 v2 字段：

- 标签
- AI 评分和解释
- RoB 工具、分项判断、总体判断、备注
- Meta 效应量、置信区间、标准误、结局、亚组
- 云端项目成员和权限

## 关键验收标准

- 双人盲筛期间不能显示对方决定。
- 排除必须记录理由。
- 揭盲后冲突识别正确。
- 所有关键操作写入审计日志。
- 导出文件能正常打开且中文不乱码。
- 大项目不能因为 localStorage 容量限制丢失主要数据。
