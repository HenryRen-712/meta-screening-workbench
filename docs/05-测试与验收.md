# 测试与验收标准

## 最低检查

每次代码改动后必须运行：

```bash
PATH="/Users/gavinren/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:/Users/gavinren/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin:$PATH" pnpm build
```

构建失败时不能视为完成。

## 页面检查

本地打开：

```text
http://127.0.0.1:5173/
```

至少确认：

- 页面不是空白。
- 标题和流程导航可见。
- 示例题录或导入题录可见。
- 角色切换可用。
- 决策按钮可见。

## 核心流程验收

每次影响筛选流程时，至少测试：

- 导入 CSV 模板。
- 导入 RIS 或 BibTeX。
- 识别重复记录。
- 筛选者 A 做出决定。
- 筛选者 B 做出不同决定。
- 揭盲后出现冲突。
- 裁决者完成裁决。
- 全文阶段记录状态和排除理由。
- 恢复旧项目后，全文候选纳入数不变，但最终 Meta 纳入数为 0，所有候选研究进入待 A/B 确认队列。
- 筛选者 A 完成最终分析确认后，筛选者 B 仍不能看到 A 的决定；B 完成后才可显示一致或冲突。
- A/B 冲突时只有裁决者可完成最终裁决。
- A/B 都选择“待定”时不得生成最终 Meta 决定，必须进入裁决队列。
- 只有 A/B 一致纳入或裁决纳入的研究显示在数据提取板块。
- 数据提取表可填写。
- 数据提取表可进入全屏工作区，支持 50%–130% 缩放、100% 恢复和 Esc 退出；退出后已有输入不变。
- 最终纳入文献 PDF 可在数据提取板块自动匹配；一键提取后字段具有原文证据、页码和 PDF 哈希，未识别字段明确留空。
- 重新提取不会覆盖人工修改值；扫描版或无文字层 PDF 不生成猜测内容。
- 导出 CSV、PRISMA、数据提取表、Word 草稿。

## 大项目验收

涉及性能、保存、导入、筛选列表时，必须测试：

- 4,000 条基础压力测试。
- 20,000 条中等压力测试。
- 30,000 条目标压力测试。

记录要求：

- 导入是否完成。
- 页面是否明显卡死。
- 自动保存状态是否正常。
- 导出是否可用。
- 测试结果写入 `测试报告/`。

## 数据验收

必须确认：

- 中文不乱码。
- DOI、PMID 不被错误截断。
- 排除理由保留。
- 审计日志包含操作者和时间。
- 项目备份 JSON 可以恢复。

## UI 验收

必须确认：

- 桌面宽屏无明显重叠。
- 窄屏布局不崩。
- 按钮文字不溢出。
- 重要操作入口清楚。
- 蓝色高级医疗 SaaS 风格不影响可读性。

## 不通过标准

出现以下情况不能交付：

- 构建失败。
- 页面空白。
- 筛选决定无法保存。
- 双人盲筛直接暴露对方决定。
- 导出文件无法打开。
- 恢复项目后核心数据丢失。
