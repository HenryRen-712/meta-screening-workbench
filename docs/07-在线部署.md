# 在线部署说明

## 目标

把 Meta 文献筛选工作台部署成联网后可直接打开的网址，不再依赖本机 `127.0.0.1:5173` 开发服务。

## 当前发布方式：GitHub Pages

当前仓库使用 `gh-pages` 分支发布静态网站：

- 源码分支：`main`
- 网页发布分支：`gh-pages`
- 发布目录来源：本地 `pnpm build` 生成的 `dist`

网页地址：

```text
https://henryren-712.github.io/meta-screening-workbench/
```

后续更新网站时：

```bash
pnpm build
```

然后把 `dist` 内容发布到 `gh-pages` 分支。

说明：原计划使用 GitHub Actions 自动部署，但当前 GitHub CLI 登录令牌没有 `workflow` 权限，无法通过 API 上传 `.github/workflows/...`。因此第一次上线采用 `gh-pages` 分支直接发布，稳定性更高，也更适合当前权限状态。

## 数据保存提醒

线上部署后，项目数据仍默认保存在当前浏览器中，不会自动同步到云端。

正式筛选时仍应定期点击“项目备份”，导出 JSON 文件。换电脑、换浏览器、清理浏览器数据后，需要用“恢复项目”导入 JSON 备份。
